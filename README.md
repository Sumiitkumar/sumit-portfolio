# Sumit Kumar's Portfolio

A modern, responsive portfolio built with **Hugo** and deployed to GitHub Pages.

## 🚀 Quick Start

```bash
cd portfolio-hugo
hugo server
```

Visit: http://localhost:1313/sumit-portfolio/

## 📂 Project Structure

```
portfolio-hugo/
├── content/        ← Edit your content here
├── themes/         ← Theme files
├── hugo.toml       ← Configuration
└── public/         ← Generated site
```

## 🚀 Deploy

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

Live at: https://sumiitkumar.github.io/sumit-portfolio/

## 📝 Edit Content

- **About:** `content/about/_index.md`
- **Projects:** `content/projects/*.md`
- **Blog:** `content/blog/*.md`
- **Site Title:** `portfolio-hugo/hugo.toml`

## 🎨 Customize

Edit colors and fonts in: `portfolio-hugo/themes/portfolio/static/css/style.css`
